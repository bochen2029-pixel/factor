## 4 · One finding, in a harness rather than in the code

The first `cjson_cross.py` run read **7 of 498** and named the codec. It was the
harness: it split the binary's stdout with Python's `str.splitlines()`, which
splits on U+0085, U+2028 and U+2029 as well as LF. Canonical JSON carries all
three **raw**, because §12 forbids escaping non-ASCII, so the first document
containing a line separator desynchronised the entire transcript. The document
was byte-identical in isolation. `run_batch` now splits on LF alone and the
comment says why. This is the same set `frame_roundtrip.py` calls
`EXTRA_SPLITTERS`, and it is a property of the transport, not of the codec.

## 7 · Ambiguities, with the default taken

Carried forward from `receipts/BOOTSTRAP_2026-09-08.md`; none is closed by code
yet, and two are now closer to biting.

1. **A2, the tape's spelling of the pinned enums. The default is changed, and
   the reason is measured.** The bootstrap receipt defaulted to writing `verb`
   and `reason` as their pinned numbers. `chain_check.py` writes names:
   `grep -n '"verb":' tests/chain_check.py` → line 438
   `"verb": ["HOLD", "LOOK", "DRAFT"][i % 3]`, line 439 `"reason": "ok"`.
   §12 is silent, so this is not a spec disagreement; it is a choice the spec
   leaves open and the harness has already made. Keeping the earlier default
   would mean the C tape and the harness compute different `h` for the same
   judgment, which is the two-heads failure §12 exists to prevent, and it would
   be found at step 5 rather than now. **New default: the name, exactly as
   `seam::verb_name` and `seam::reason_name` spell it, which is the same
   spelling the harness writes.** Still the operator's to pin, because the plan
   hash covers both fields.
2. **A3, the declared width of `seg` and `row_orig`.** Taken as 64-bit and
   therefore decimal strings, matching the harness. Implemented that way.
3. **A1, frame flag bit 3.** Not yet reached; step 3 decides it. Default
   unchanged: the spec wins, bit 3 is `lossy_amount` and is accepted.
