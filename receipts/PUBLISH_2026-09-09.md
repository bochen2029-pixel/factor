## 4 · Held back, with the reason

Three files stay in the working tree and are named in `.gitignore` with the
reason written beside them, so a later session cannot add them by accident.

1. **`DRIVING_THE_ORGANIZATION.md`** — organization-radius material whose stated
   source is a third party's PDF, `AI-OPO 1 1 (1).pdf`, and which sets out a
   named US organ procurement organization's clinical workflow stage by stage,
   including donor-management detail: vitals, gases, vasopressor titration inside
   physician-set ranges. It is not this repository's to distribute and M0 does
   not need it.
2. **`DRIVING_THE_ORGANIZATION_NOTES-FROM-55555.md`** — the notes on the same
   file, carrying the same material.
3. **`qc/O4_chatter.md`** — a review whose citations are line references into
   private session transcripts on this machine, across four different projects,
   and which quotes the operator's own correspondence.

Everything these three contributed to the design is already in
`BLUEPRINT_v0.2.md` and its six amendments, which are published in full. The
other eleven `qc/` files are published; they are design review and cite public
vendor documentation.

**This is a judgment, not a rule.** Adding any of the three is one command and
the operator's call. Note that a public git history is not a redaction: if a
held-back file is added later and then removed, it stays in the history and in
GitHub's caches. So each is held back now rather than published and withdrawn.
